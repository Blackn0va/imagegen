#   FALSCH: erst requirements.txt, dann diese Datei. pip hat dann schon das

#           an und lässt das cu-Wheel liegen. Ergebnis: CUDA-DLLs im Bundle,
#           aber torch.cuda.is_available() == False.
#   RICHTIG (macht build-windows.ps1 so):
#     pip install --index-url https://download.pytorch.org/whl/cu126 torch torchvision torchaudio
#     pip install -r requirements-cuda.txt --extra-index-url https://download.pytorch.org/whl/cu126
#     pip install -r requirements.txt
#
# Prüfen: python -c "import torch;print(torch.__version__, torch.version.cuda)"
# Muss "…+cu126 / 12.6" zeigen, nicht "…+cpu / None".

# CPU-Build versehentlich GPU-Wheels.
